- Kali Linux

## Testing Methodology

Identify → Test → Observe → Remediate → Document

## Key Takeaways

- Web applications should validate and protect user input.
- Authentication and authorization are different security controls.
- Security testing should be performed only on authorized targets.
- Vulnerabilities should be documented with clear evidence.
- Identified vulnerabilities should be followed by appropriate remediation.
