# OWASP ZAP Analysis

## Objective

To analyze the local web application for common security issues using
OWASP ZAP in a controlled testing environment.

## Target

Local lab application.

## Tool

OWASP ZAP

## Testing Method

- Application discovery
- Passive analysis
- Security alerts review

## Observations

To be documented after the security testing is performed.

## Alerts

To be documented based on the actual ZAP scan results.

## Evidence

Screenshots will be added after testing.

## Recommendations

To be documented based on the identified findings.
