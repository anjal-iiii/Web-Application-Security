# Web Application Security

A practical web application security project focused on understanding
web application fundamentals, OWASP Top 10 vulnerabilities,
security testing, vulnerability reporting, remediation, and
OWASP ZAP analysis.

## Objectives

- Understand how web applications work
- Learn HTTP requests and responses
- Understand cookies, sessions, authentication and authorization
- Study the OWASP Top 10
- Practice vulnerability identification in a controlled lab
- Analyze web applications using OWASP ZAP
- Document vulnerabilities and remediation
- Follow secure coding practices

## Security Testing Methodology

Identify → Test → Observe → Remediate → Document

## Tools

- Kali Linux
- Web Browser
- OWASP Juice Shop
- OWASP ZAP
- GitHub
