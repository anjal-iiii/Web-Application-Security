# Web Application Security Demo

## 1. Introduction

This demonstration presents the practical web application security
testing performed during the project.

## 2. Lab Environment

The testing environment includes:

- Kali Linux
- Web Browser
- OWASP Juice Shop
- OWASP ZAP

## 3. Web Application Basics

The demonstration begins with basic concepts including:

- HTTP
- HTTP methods
- Cookies
- Sessions
- Authentication
- Authorization

## 4. OWASP Top 10

The relevant OWASP Top 10 vulnerabilities studied during the project
are explained.

## 5. Vulnerability Testing

Selected vulnerabilities identified in the controlled local lab
environment are demonstrated.

## 6. Evidence

Screenshots and testing evidence are presented for the documented
findings.

## 7. OWASP ZAP Analysis

OWASP ZAP is used to observe application traffic and identify
security-related alerts.

## 8. Remediation

Recommended security measures for the identified issues are explained.

## 9. Conclusion

The project demonstrates a basic workflow for identifying,
documenting, and remediating web application security issues.
