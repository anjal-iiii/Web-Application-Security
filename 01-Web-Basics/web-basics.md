# Web Application Basics

## HTTP

HTTP (HyperText Transfer Protocol) is a protocol used for communication
between a client and a web server.

## HTTP Request

An HTTP request is sent by a client, such as a browser, to communicate
with a web server and request a resource or perform an action.

## HTTP Response

An HTTP response is sent by the server after processing the client's request.

## HTTP Methods

- GET – Retrieve data
- POST – Send or create data
- PUT – Update existing data
- DELETE – Delete data

## HTTP Status Codes

- 200 – OK
- 201 – Created
- 301 – Redirect
- 400 – Bad Request
- 401 – Unauthorized
- 403 – Forbidden
- 404 – Not Found
- 500 – Internal Server Error

## Cookies

Cookies are small pieces of data stored by a browser and sent with
requests to help websites maintain information about a user or session.

## Sessions

Sessions allow a web application to maintain a user's state across
multiple requests.

## Authentication

Authentication verifies the identity of a user.

Example:
Username and password login.

## Authorization

Authorization determines what an authenticated user is allowed to access
or perform.

## Authentication vs Authorization

Authentication = Who are you?

Authorization = What are you allowed to do?

## Web Application Security

Web application security involves protecting web applications,
their data, users, and services from unauthorized access and attacks.

## Security Testing Methodology

Identify → Test → Observe → Remediate → Document
