# Web Application Basics

## What is a Web Application?

A web application is a software application that runs through a web browser
and communicates with a web server.

## Client and Server

The client is usually the browser used by the user.

The server processes requests, performs operations and returns responses.

Client → HTTP Request → Server
Client ← HTTP Response ← Server

## HTTP

HTTP (Hypertext Transfer Protocol) is used for communication between a
web browser and a web server.

## HTTP Methods

- GET – Retrieve data
- POST – Send or create data
- PUT – Update data
- DELETE – Delete data

## HTTP Status Codes

- 200 – OK
- 201 – Created
- 301/302 – Redirection
- 400 – Bad Request
- 401 – Unauthorized
- 403 – Forbidden
- 404 – Not Found
- 500 – Internal Server Error

## Cookies

Cookies are small pieces of data stored by the browser and sent with
requests to maintain information such as preferences or sessions.

## Sessions

A session allows a web application to maintain a user's state between
multiple requests.

## Authentication

Authentication verifies who the user is.

Example:
Username + Password

## Authorization

Authorization determines what an authenticated user is allowed to access.

Example:
Normal user → User dashboard
Admin → Admin dashboard

## Authentication vs Authorization

Authentication = Who are you?

Authorization = What are you allowed to do?
