# Security Lab

This folder contains the practical web application security lab setup,
testing methodology, and evidence collected during the project.

## Lab Environment

- Kali Linux
- Web Browser
- OWASP Juice Shop
- OWASP ZAP

## Objective

To identify, understand, test, and document common web application
security vulnerabilities in a controlled local environment.

## Testing Methodology

Identify → Test → Observe → Remediate → Document

## Scope

Testing will be performed only on the locally hosted lab application.

## Evidence

Screenshots and other testing evidence will be added to the
screenshots folder.
